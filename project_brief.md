# My agent: code-assistant
One-liner: A conversational agent that helps software developers write, review, and debug code with a catalog of code snippets and live developer tools.

Tool coverage:
- Memory: User coding preferences, preferred frameworks, and past debugging history
- Tools: Code review, documentation lookup, git helper, and error diagnosis
- Catalog/UI: Collection of reusable code snippets, design patterns, and dependency tables
- Image gen: System architecture flowcharts and component diagrams
- Sandbox: Python code execution and algorithm benchmarking

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch: code sandbox for execution, git integration, Cloud Trace
